# riskgg.com

Static site for Risk Governance Group, LLC. No framework, no build step on Vercel. The HTML files at the repo root are what gets served.

## Layout

| Path | What it is |
|---|---|
| `*.html`, `articles/*.html` | The pages. Generated by `tools/build.py`. Edit the templates there, not these files. |
| `styles.css` | All styling. Source of truth, edit directly. |
| `assets/` | Favicon, OG image, portrait, PDFs. Source of truth, edit directly. |
| `tools/build.py` | Page templates and copy. Run `python3 tools/build.py` from the repo root after any copy change. |
| `vercel.json` | Clean URLs, security headers, 301 redirects from every old WordPress address. |
| `sitemap.xml`, `robots.txt` | Generated by the build. |
| `_preview/` | Build output with `.html` links for local file viewing. Gitignored. |

## Editing copy

1. Open `tools/build.py`. Each page is a Python string near the top (INDEX, AI_OVERSIGHT, CYBER, TEAM, BODY_OF_WORK, PERSPECTIVES, CONTACT, PRIVACY, TERMS, and the two article bodies).
2. Edit the text.
3. From the repo root run `python3 tools/build.py`.
4. Commit everything, including the regenerated HTML. Push. Vercel deploys on push.

## House rules carried into the copy

- Zero em dashes and zero en dashes. The build check in DEPLOY.md fails if one appears.
- Banned words: robust, leverage, holistic, seamless, empower, stakeholder, unlock, unprecedented, journey, transform, navigate, delve, cutting-edge, best-in-class, RegRisk, north star.
- The Center for AI Oversight appears only as a founder credential and as cited published work, with the separation line in the footer. No Center logo, no advisory board, no partnership language.
- No maturity model content until counsel settles IP ownership.

See DEPLOY.md for the GitHub and Vercel steps.
